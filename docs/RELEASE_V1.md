# Release V1

## Status

V1 is locked as a private sideload release candidate as of 2026-06-08.

Pat approved the final visual direction in the Windows Venu Sq 2 simulator after these design passes:

- Full-screen Progress Pride background
- Transparent active-mode UI, no opaque cards
- Bolder date, time, metric values, and icons
- 2px text shadows for readability
- Compact 2x2 metric grid
- Thin inset rainbow divider
- Corrected AM/PM spacing

## Built Artifacts

Generated by:

```sh
scripts/build.sh venusq2
scripts/build.sh venusq2m
```

Current artifacts:

```text
build/PrideDashboard-venusq2.prg
build/PrideDashboard-venusq2m.prg
```

Build artifacts are ignored by git. Rebuild them from source for sideload.

## Validation Completed

- `venusq2` build succeeds.
- `venusq2m` build succeeds.
- Windows-local VS Code can run the Venu Sq 2 simulator.
- Simulator screenshots were used to tune the Venu Sq 2 layout.
- Final simulator pass was visually approved by Pat before release cleanup.

## Known Constraints

- This WSL install is ARM64. Garmin's Linux SDK Manager and simulator are x86-64 binaries, so simulator testing happens on Windows.
- The local WSL build uses Garmin device definitions symlinked from the Windows SDK Manager install.
- V1 uses Garmin built-in fonts. Custom bitmap fonts are deferred.
- Weather is intentionally excluded from v1.
- Public Connect IQ Store packaging/review is out of scope for v1.

## Sideload Notes

For private testing, use the target-specific `.prg`:

- Standard Venu Sq 2: `build/PrideDashboard-venusq2.prg`
- Venu Sq 2 Music: `build/PrideDashboard-venusq2m.prg`

Copy the appropriate PRG to the watch's `GARMIN/APPS` directory when mounted over USB.
